# Academic Projects Portfolio

Portfólio de projetos acadêmicos de **Thiago Wyse**, estudante de **Ciência da Computação**. Este repositório organiza trabalhos desenvolvidos durante a graduação e apresenta, de forma objetiva, as soluções construídas, os conceitos aplicados e as competências técnicas praticadas.

O objetivo é oferecer a recrutadores e profissionais de tecnologia uma visão clara da minha evolução em desenvolvimento de software, estruturas de dados e resolução de problemas.

## Projetos

| Projeto | Descrição | Disciplina | Tecnologias | Acesso |
| --- | --- | --- | --- | --- |
| Infix Expression Evaluator | Aplicação de terminal que converte expressões infixas para pós-fixas e calcula o resultado com implementações estáticas e dinâmicas de pilhas e filas. | Estruturas de Dados | Java | [Ver projeto](./infix-expression-evaluator/) |

## Competências demonstradas

- Desenvolvimento orientado a objetos com Java e generics.
- Implementação de tipos abstratos de dados sem bibliotecas de coleções.
- Uso de pilhas, filas circulares e estruturas encadeadas.
- Conversão e avaliação de expressões matemáticas.
- Validação de entrada e tratamento de erros sintáticos.
- Criação de testes executáveis para diferentes implementações.
- Decomposição de problemas e separação de responsabilidades.

## Execução

Cada projeto possui requisitos e comandos próprios em seu README. Para o projeto Java deste portfólio, é necessário ter um JDK instalado e os comandos `javac` e `java` disponíveis no terminal.

Consulte as [instruções do projeto](./infix-expression-evaluator/#como-executar) para compilar, executar e testar a aplicação.

## Contexto acadêmico

Os projetos deste repositório foram desenvolvidos durante a graduação em Ciência da Computação. Eles registram a aplicação prática de conteúdos estudados em aula e preservam o código original sempre que possível.
